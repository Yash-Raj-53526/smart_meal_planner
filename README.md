# Smart Recipe & Meal Planner

A command-line Python application that matches the ingredients you already
have against a recipe database, tells you what you can cook **right now**,
what you're **almost ready** for, and what you'd need to buy — then builds
you a 7-day meal plan and a shopping list automatically.

Built for **Computational Thinking and Programming (2026CSAE100)** as a
5-person group project.

## Features

- **Recipe Database** — add, view, edit, and delete recipes, stored in `recipes.csv`.
- **Pantry Manager** — track ingredients and quantities, stored in `pantry.csv`.
- **Match & Rank Engine** *(core computational feature)* — compares your
  pantry against every recipe using set operations, and classifies each
  recipe as `Ready now`, `Almost there`, or `Needs shopping`, ranked best-first.
- **Weekly Meal Planner** — auto-generates a 7-day, 3-meals-a-day plan that
  avoids repeating the same recipe too often, and builds a shopping list of
  everything you're missing.
- **Reports** — most-cooked recipes, a meal-category breakdown, a nutrition
  summary, and a `matplotlib` bar chart, all built from your meal history.

## Setup / Installation

1. **Get the project folder** (unzip it, or `cd` into it if already extracted):
   ```bash
   cd smart_meal_planner
   ```

2. **(Recommended) Create a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate        # on Windows: venv\Scripts\activate
   ```

3. **Install the one dependency:**
   ```bash
   pip install -r requirements.txt
   ```

That's it — no other configuration is needed.

## Running the Application

From inside the `smart_meal_planner` folder:

```bash
python3 main.py
```

You'll see:

```
Loaded 20 recipes and 15 pantry items.

==================================================
 Smart Recipe & Meal Planner
==================================================
1. View / manage recipes
2. View / manage pantry
3. Find recipes I can cook now (match & rank)
4. Generate weekly meal plan + shopping list
5. View reports (most cooked, nutrition summary)
6. Exit
Choose an option (1-6):
```

Type a number and press Enter to navigate. Every change you make (adding a
recipe, updating your pantry, saving a meal plan) is written straight back
to the CSV files, so your data persists between runs.

## Using the Application

| Option | What it does |
|---|---|
| **1. Manage recipes** | View all recipes (or filter by category), add a new one, edit an existing one, or delete one. Every input is validated — try an empty name, a duplicate name, an invalid category, or non-numeric calories to see it handled gracefully. |
| **2. Manage pantry** | View your pantry, add an ingredient (merges quantities if it already exists with the same unit), update a quantity, or remove an ingredient. |
| **3. Match & rank** | Optionally filter by `breakfast`/`lunch`/`dinner`, then see every recipe ranked by how ready you are to cook it, with the exact missing ingredients listed. |
| **4. Generate meal plan** | Builds a full 7-day plan (breakfast/lunch/dinner), prints it as a grid, shows the combined shopping list, and asks if you'd like to save it to your meal history. |
| **5. View reports** | Most-cooked recipes, a category breakdown, a nutrition summary, and a bar chart (saved as `reports_chart.png` in the project folder — open it with any image viewer). |
| **6. Exit** | Quits the program. |

Type `cancel` at almost any prompt inside the Recipe or Pantry menus to back
out without making a change.

## Running the Tests

The project ships with **68 automated unit tests** covering all 5 modules,
written with Python's built-in `unittest` framework (no extra install needed).

**Run the whole suite:**
```bash
python3 -m unittest discover -s tests -v
```

**Run a single module's tests:**
```bash
python3 -m unittest tests.test_matching_engine -v
```

**If you have `pytest` installed**, the same test files work with it too
(they're plain `unittest.TestCase` classes, which pytest discovers natively):
```bash
pytest tests/ -v
```

Expected output ends with:
```
----------------------------------------------------------------------
Ran 68 tests in 0.4s

OK
```

## How the Core Algorithm Works

The heart of this project is `matching_engine.py`. For every recipe, it
treats both the recipe's ingredient list and your pantry as **Python sets**,
then uses set intersection and difference:

```python
have         = recipe_ingredients & pantry_ingredients   # what you already have
missing      = recipe_ingredients - pantry_ingredients    # what you still need
match_score  = len(have) / len(recipe_ingredients)         # 0.0 - 1.0
```

Recipes are then classified:

| Match score | Status |
|---|---|
| 100% | **Ready now** |
| 70% – 99% | **Almost there** |
| below 70% | **Needs shopping** |

...and ranked with the highest match score first, breaking ties by fewest
missing ingredients, then by shortest cook time.

See `docs/diagrams/flowchart_matching.png` for the full flowchart, and
`docs/diagrams/flowchart_overall.png` for how this fits into the overall
program flow.

## Troubleshooting

- **`ModuleNotFoundError: No module named 'matplotlib'`** — run
  `pip install -r requirements.txt` (or `pip install matplotlib`) first.
  Every feature except the reports bar chart (option 5 → 4) works even
  without matplotlib installed.
- **`No meal history yet` when viewing reports** — you need to generate and
  save a meal plan first (option 4, then answer `y` when asked to save).
- **Recipe/pantry changes don't seem to persist** — make sure you're running
  `main.py` from inside the `smart_meal_planner` folder, since the CSV paths
  are relative to the current working directory.
- **Want to start fresh?** — replace `recipes.csv`/`pantry.csv` with just
  their header rows, and truncate `meal_history.csv` to its header row.
